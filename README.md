# AI Advent Challenge #10

Решения практических заданий [AI Advent Challenge #10](https://mobiledeveloper.tech/ai_advent_10): LLM, агенты, MCP, RAG и автоматизация.

## Проекты

| День | Проект | Язык и стек | Статус |
| --- | --- | --- | --- |
| 01 | [Запрос к LLM через API](projects/day-01-llm-api/) | Python, requests, CLI | Описание подготовлено, реализация впереди |

## Организация репозитория

Каждое задание находится в отдельной папке `projects/day-NN-topic/` и представляет собой самостоятельный проект. Проекты могут использовать разные языки и инструменты.

В README каждого проекта указаны условие, результат, зависимости и инструкция запуска. Устанавливайте зависимости из папки выбранного проекта. Для Python используйте отдельное виртуальное окружение `.venv` внутри проекта.

Новые папки добавляются по мере появления заданий. Если задания развивают один проект, в описании указываются связи между ними; сданные версии можно отмечать Git-тегами.

## Настройки

API-ключи задаются через переменные окружения и не сохраняются в исходниках. Файлы `.env` с локальными настройками исключены из Git. В `.env.example` допускаются только примеры без настоящих секретов.

Наличие `.env.example` само по себе не включает автоматическую загрузку `.env`: способ настройки описывается в README конкретного проекта.

## Формат описания задания

- Условие и ожидаемый результат.
- Язык и технологии.
- Что реализовано.
- Установка, настройка и запуск.
- Пример результата и ссылка на демонстрацию, если она требуется.
