## 1. Строгая схема, попытка 1

**Запрос:**

````text
Предложи три учебных проекта на Python для начинающего. Для каждого укажи название и одним коротким предложением объясни, чему он научит.
````

**Условия:**

````text
Формат: JSON с единственным строковым полем answer.
Явный лимит токенов не задан; используется лимит Cloudflare.
Строгая JSON Schema через API: answer обязателен, лишние поля запрещены.
Модель: @cf/meta/llama-3.3-70b-instruct-fp8-fast.
temperature: 0.6.
````

**Вывод LLM:**

````text
{"answer": "1. **Игра \"Камень-Ножницы-Бумага\"**: научит создавать простую игру с использованием условных операторов и функций. 2. **Управление личными финансами**: научит работать с данными, структурами и файлами для ведения личных финансов. 3. **Чат-бот**: научит создавать простого чат-бота с использованием библиотеки NLTK для обработки естественного языка."}
````

## 4. Описание формата + stop sequence, попытка 1

**Запрос:**

````text
Предложи три учебных проекта на Python для начинающего. Для каждого укажи название и одним коротким предложением объясни, чему он научит.
Верни только JSON-объект с единственным обязательным полем answer (строка с ответом на вопрос). Других полей быть не должно. Не добавляй пояснения вне JSON и Markdown-обёртку.
Сразу после JSON напиши маркер <END>, затем закончи ответ.
````

**Условия:**

````text
Формат: JSON с единственным строковым полем answer.
Явный лимит токенов не задан; используется лимит Cloudflare.
Stop sequence: ["<END>"].
Модель: @cf/meta/llama-3.3-70b-instruct-fp8-fast.
temperature: 0.6.
````

**Вывод LLM:**

````text
{"answer": "Проект \"Калькулятор\" научит работать с переменными и операторами, проект \"Угадай число\" научит использовать циклы и условные операторы, а проект \"Трекер задач\" научит работать с файлами и структурами данных."}

````
