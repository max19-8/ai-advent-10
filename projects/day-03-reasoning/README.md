# День 03. Разные способы рассуждения

Сравнение четырёх способов запроса и уровней `low` / `high` одной модели
GPT-OSS 20B через Cloudflare Workers AI.

**[REPORT.md](REPORT.md)** — единый итоговый документ: условия вопросов,
ответы модели, таблицы токенов и времени, ручная проверка и общий вывод.
**[results.json](results.json)** — выбранные исходные прогоны и ручные оценки
в одном файле. Есть пять вопросов с полными low/high и отдельно первый
частичный прогон моста.

## Установка

Python 3.9+, requests и python-dotenv. Из корня репозитория:

```bash
cd projects/day-03-reasoning
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
cp -n .env.example .env
```

Заполните `CLOUDFLARE_API_TOKEN` и `CLOUDFLARE_ACCOUNT_ID` в соседнем `.env`.
Модель по умолчанию — `@cf/openai/gpt-oss-20b`, также разрешена GPT-OSS 120B.
Окружение имеет приоритет над `.env`. Если ранее экспортировали Llama,
выполните `unset CLOUDFLARE_MODEL`. В сохранённых прогонах использовалась
только GPT-OSS 20B.

## Запуск

```bash
.venv/bin/python main.py --route
```

| Аргумент | Вопросы | Запросов к API |
| --- | --- | ---: |
| Без аргумента | Ручка; станки | 20 |
| `--easy` | Насосы и слив | 10 |
| `--knapsack` | Рюкзак | 10 |
| `--route` | Упрощённый маршрут с купоном | 10 |
| `--hard` | Мост и фонарь | 10 |

Флаги выбора набора взаимно исключают друг друга. `--check` можно добавить
к любому набору: выполнятся два прямых запроса первой задачи, low/high.

Четыре способа: прямой, «решай пошагово», составление промпта и его выполнение
вторым запросом, аналитик/инженер/критик с общим итогом. В составлении промпта v2
автор и решатель получают разные инструкции, весь промпт передаётся во второй
запрос. Оба этапа показаны в отчёте, оценивается второй ответ, затраты включают
оба обращения. Эксперты — роли внутри одного ответа, а не независимые агенты.

API: `/ai/v1/responses`, reasoning low/high, без стриминга и истории.
По одному запуску каждого варианта, порядок low → high, автоматических
повторов нет. Температура, `max_output_tokens` и `max_tokens` не задаются,
клиентский HTTP-таймаут отключён. Ограничения сервиса и сетевые ошибки возможны.
Запросы расходуют квоту аккаунта Cloudflare.

## Отчёт и проверка

После каждого обращения обновляются локальные `results/<UTC-время>.json`
и `.md`. В конце тот же Markdown целиком печатается в терминал вместе с путями
файлов. Запуски не перезаписываются. Локальная папка `results/` игнорируется Git;
выбранные результаты для репозитория собраны в `REPORT.md` и `results.json`.

При ошибке сети/API или незавершённом ответе прогон останавливается,
частичный результат сохраняется и печатается. Ctrl+C сохраняет уже полученные
данные. Коды завершения: 0 — выполнен, 1 — ошибка, 130 — прерывание.
Неверный численный ответ не меняет код завершения эксперимента.

Проверяется последняя строка `Ответ: <число>` по известному эталону.
Нераспознанный формат остаётся для ручной оценки. Правильность всех пояснений
оценивается вручную. Токены берутся из usage, время включает сеть и очередь.
Отсутствующая статистика не считается нулём. API-токен и Account ID скрываются
в сохраняемых данных и напечатанном отчёте. Старые прогоны имеют другой
протокол промптов и лимитов, что отмечено в едином отчёте.

## Файлы и тесты

- `main.py` — запуск и настройки.
- `tasks.py` — вопросы, эталоны, проверка итогового числа.
- `experiment.py` — промпты, API, измерения.
- `report.py` — сохранение и печать отчёта одного запуска.
- `test_main.py` — тесты и независимая проверка эталонов.

```bash
python -m unittest -v
```

Тесты подставляют HTTP-ответы и не расходуют квоту. Проверяются также
целостность выбранных данных и ручные оценки из `results.json`.
Для сдачи запишите видео с запуском, итоговой таблицей и объяснением выводов.

Документация: [Responses API Cloudflare](https://developers.cloudflare.com/workers-ai/configuration/open-ai-compatibility/),
[GPT-OSS 20B](https://developers.cloudflare.com/workers-ai/models/gpt-oss-20b/).
