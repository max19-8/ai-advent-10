# День 01. Запрос к LLM через API

## Задание и решение

Минимальная Python-программа отправляет вопрос в LLM через API, получает ответ и выводит его в консоль.

Стек: Python 3.9+, `requests`, официальный REST API Cloudflare Workers AI. SDK и собственный сервер не нужны. Один запуск — один вопрос; история не сохраняется.

Модель: `@cf/meta/llama-3.1-8b-instruct`. Бесплатный план Workers AI предоставляет 10 000 Neurons в день: это единицы вычислений, не число запросов. На Workers Free при исчерпании квоты запросы останавливаются. Для этого проекта не требуется переходить на Workers Paid. Программа ограничивает ответ 512 токенами.

## Установка

Из корня репозитория:

```bash
cd projects/day-01-llm-api
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

## Настройка Cloudflare

1. Войдите в [панель Cloudflare](https://dash.cloudflare.com/), откройте Workers AI и выберите **Use REST API**.
2. Нажмите **Create a Workers AI API Token** и создайте токен по предложенному шаблону для своего аккаунта. При ручном создании нужны разрешения Workers AI Read и Edit.
3. Скопируйте **Account ID** с той же страницы. Это не Zone ID и не адрес электронной почты.
4. Используйте план Workers Free и модель по умолчанию. Разворачивать Worker, добавлять домен или сайт не требуется.

В macOS с zsh выполните следующую команду без изменений:

```zsh
read -rs 'CLOUDFLARE_API_TOKEN?Вставь токен Cloudflare и нажми Enter: '
```

В ответ на приглашение вставьте токен и нажмите Enter. Ввод скрыт. Затем:

```zsh
export CLOUDFLARE_API_TOKEN
printf '\n'
read -r 'CLOUDFLARE_ACCOUNT_ID?Вставь Account ID и нажми Enter: '
export CLOUDFLARE_ACCOUNT_ID
```

Переменные действуют только в этом терминале и для запущенных из него программ. Не отправляйте токен в чат и не записывайте его в Git. Файл `.env.example` только перечисляет настройки; программа не загружает `.env` автоматически. Ключ Gemini больше не используется.

## Запуск

В том же терминале с активным окружением и заданными переменными:

```bash
python main.py
```

Пример интерфейса (не запись реального API-вызова):

```text
Введите вопрос: Объясни в одном предложении, что такое API.
Ожидание ответа…

Ответ:
API — это интерфейс для взаимодействия программ.
```

Необязательная переменная `CLOUDFLARE_MODEL` позволяет выбрать другую модель Cloudflare. Форматы ответов у моделей отличаются; этот минимальный клиент рассчитан на `result.response` модели по умолчанию. Перед переключением проверьте цену и доступность модели на Free-плане.

## Ошибки и проверка

Пользователь подтвердил успешный запуск программы с реальным Cloudflare API и получение ответа модели. Обработка настроек, ответов и ошибок дополнительно проверена локально с имитацией HTTP-запросов.

Программа проверяет настройки и пустой ввод, обрабатывает сетевые ошибки, тайм-ауты, ошибки API и пустой ответ. При отказе API выводит диагностические сообщения Cloudflare (до трёх, каждое до 1000 символов), удаляя из них токен. Ошибки завершают процесс с ненулевым кодом.

Для проверки интеграции отправьте обычный вопрос с действующими настройками. Непустой ответ подтвердит работу API. HTTP 401/403 требует проверки токена, прав и Account ID; HTTP 429 — квоты или частоты запросов. Чтение сайта Cloudflare само по себе не подтверждает доступ к Workers AI API.
