# День 01. Запрос к LLM через API

## Задание

Написать минимальную программу, которая отправляет запрос в LLM через API, получает ответ и выводит его в консоль или простой интерфейс.

## Выбранное решение

- Язык: Python.
- Интерфейс: консоль (CLI).
- HTTP-запросы: библиотека `requests`, без SDK провайдера.
- API-ключ: переменная окружения.
- Сценарий: один вопрос — один ответ.

## Как будет работать

1. Программа читает настройки и проверяет наличие API-ключа.
2. Пользователь вводит вопрос в терминале.
3. Программа проверяет, что вопрос не пустой, и отправляет HTTP-запрос к API выбранного провайдера.
4. Из JSON-ответа извлекается текст модели и выводится в консоль.
5. При проблемах с сетью, авторизацией, лимитами или тайм-аутом выводится понятное сообщение.

## Текущий статус

Подготовлено описание проекта. Код пока не реализован; провайдер, модель и формат запроса будут выбраны перед реализацией.

## Установка и запуск

Команды установки и запуска будут добавлены вместе с работающей программой. Файлов `main.py` и `requirements.txt` пока нет.

Файл `.env.example` содержит пример имени переменной для ключа. Настоящий ключ в репозиторий не добавляется. Автоматическая загрузка `.env` пока не реализована.

## Ожидаемый результат

```text
Введите вопрос: Что такое LLM?
Ожидание ответа…

Ответ:
LLM — это большая языковая модель…
```

Это иллюстрация планируемого интерфейса, а не результат запуска готовой программы.
